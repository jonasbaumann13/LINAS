1. Systemvoraussetzungen:

- ist nur Java, also fast alles *g*
- Wichtig ist aber JDK 1.4 oder hoeher! ! !


2. Starten:

Zum Starten des Spieles muss die „linas.bat“ umgeschrieben werden.
Der Pfadname gibt den Ort an, an welchem sich das Verzeichnis bin des JDK
befindet. Der Pfadname muss dementsprechend verändert werden.


3. Verbindungsaufbau:

Wenn sie ein Spiel eröffnen wollen, brauchen sie keine IP - Adresse eingeben und können gleich
auf "Spiel eröffnen" klicken. Nun wartet das Programm auf einen Client.
Einem Spiel beitreten können Sie nur, wenn bereits ein anderer Spieler einen Server auf-
gemacht hat und Sie die IP des Servers in das entsprechende Feld eingegeben haben.
Probleme können durch eine falsche IP oder Firewalls entstehen!


4. Spielvorbereitung:

Ist die Verbindung erfolgreich aufgebaut, so öffnet sich ein weiteres Fenster. Hier können Sie nun
eingeben, mit welchen Einheiten Sie ihrem Gegner gegenüber treten wollen. Jede Einheit kostet
dabei eine unterschiedliche Anzahl an Punkten.
Der Server muss warten, bis der Client seine Eingabe bestätigt hat. Dann kann auch er seine
Eingaben bestätigen.


5. Einheiten setzen:

Rechts oben in dem Fenster sehen Sie die Einheiten, welche Sie noch platzieren können.
Unter ihrem Nick-Namen wird die Einheit angezeigt, welche sie als nächstes setzen können. 
Die angezeigte Einheit setzen Sie ganz einfach, indem Sie auf die gewünschte Stelle auf 
dem Hexafeld mit der linken Maustaste klicken. Sie dürfen ihre Einheiten  allerdings nur 
auf Felder setzen, die weiss sind. 
Es stellt kein Problem dar, wenn Sie sich verklickt haben. In diesem Fall können Sie einfach 
eine andere Stelle wählen. Auch wenn Sie schon andere Einheiten gesetzt haben, können 
Sie die vorher gesetzten noch verschieben. Dazu müssen Sie diese nur anklicken und auf 
eine andere Stelle setzen. 
Wenn Sie alle Einheiten gesetzt haben, so können Sie auf "Fertig" klicken. Haben Sie das 
Spiel allerdings eröffnet, müssen Sie wieder auf den Client warten, bevor Sie das Spiel 
beginnen können.


6. Das Spiel:

Linas ist ein auf Runden basierendes Spiel, was bedeutet, dass es mehr um Nachdenken als um
schnelle Reaktion geht. Jede Einheit besitzt am Anfang einer Runde eine gewisse Anzahl an
Zugpunkten. Jede Aktion kostet einiger dieser Punkte, woraus folgt: Wenn keine Punkte mehr
vorhanden sind, kann die Einheit in dieser Runde nichts mehr machen.
Die Aktionen belaufen sich auf die Bewegung und den Angriff.
Bewegen können Sie die Einheiten mit den Tasten 1, 2, 3, 4, 5, 6 auf dem Numpad:
1 - links unten
2 - unten
3 - rechts unten
4 - links oben
5 - oben
6 - rechts oben

Wenn Sie eine Einheit ihren Wünschen entsprechend gesetzt haben, können Sie auf "Weiter"
klicken (oder "+" auf ihrer Tastatur) um die nächste Einheit anzuwählen und zu bewegen. Sie
können auch die Einheit direkt mit der linken Maustaste anwählen.
Haben Sie dann ihren Feind entdeckt, so können sie sich die feindliche Einheit auch erst einmal
genauer angucken. Wenn Sie diese mit der linken Maustaste anklicken sehen sie die übrigen
Trefferpunkte (TP) der feindlichen Einheit.
Jede Einheit hat eine bestimmte Anzahl an TP. Wenn Sie angegriffen wird erleidet Sie in der Regel
Schaden. Diese Schadenspunkte werden von den TP der feindlichen Einheit abgezogen. Sinken
die TP auf oder unter 0, so ist die Einheit zerstört. Eine Grobübersicht über die Trefferpunkte ver-
leiht die leiste rechts neben den Einheiten. Sie gibt ungefähr die Prozent der noch vorhandenen
Trefferpunkte wieder.
Natürlich können Sie mit ihren Einheiten schießen. Dabei sollten Sie darauf achten, wohin Sie
schießen. Sie können auch ihre eigenen Einheiten treffen oder aus Versehen ins Leere schießen.
Sie feuern auf das Feld, welches Sie mit der rechten Maustaste anklicken. Dabei muss aber das
Feld in der Reichweite ihrer angewählten Einheit sein. (Bei der Artillerie darf es aber auch nicht zu
nah sein, da diese eine Mindestreichweite besitzt!)
Der Schaden den Sie verursachen hängt von verschiedenen Faktoren ab.

1. Die Feuerkraft der Einheit - der maximale Schaden
2. Die Entfernung zum Ziel - je weiter entfernt, desto wahrscheinlicher ein geringerer Schaden
3. Der Zufallsgenerator - tja, etwas Spannung muss ja auch sein!

Die Artillerie zum Beispiel hat über den normalen Schaden den Sie anrichtet hinaus noch einen
Gebietsschaden. Dieser betrifft alle Felder um das Zielfeld herum. Der Schaden, den Einheiten
in diesem Bereich erleiden beträgt bei der Artillerie die Hälfte des ansonsten ermittelten normalen
Schadens. Also Acht geben auf die eigenen Einheiten bzw. gute Gelegenheiten nutzen!!!

Dies soll es nun zu LINAS auch gewesen sein. Ich wünsche Ihnen viel Spaß am Spiel.
